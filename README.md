# موقع مؤسسة المقبل للديكور والدهانات والترميم والتشطيب بالرياض

موقع إلكتروني ثابت (Static Site) فائق السرعة، مبني بـ Node.js خالص وخفيف (بدون أطر عمل ثقيلة)، مهيأ بنسبة 100% للجوال، ومتوافق تماماً مع محركات البحث (SEO) وحملات Google Ads، وجاهز للنشر المباشر عبر **GitHub** و**Cloudflare Pages**.

---

## 1. المميزات التقنية والمعمارية للمشروع

1. **السرعة وخفة الحجم (Core Web Vitals):** صفر مكتبات ضخمة (Vanilla JS + CSS موحد).
2. **هيدر وفوتر وأزرار تواصل موحدة:** تدمج داخل ملفات الـ HTML الناتجة مسبقاً (Pre-rendered) لضمان أرشفة الروابط في جوجل.
3. **أزرار تواصل ثابتة يمين الشاشة:** زرا الاتصال والواتساب ثابتان في الجانب الأيمن مع حركة نبض خفيفة تحترم معيار `prefers-reduced-motion`.
4. **زر صعود للأعلى ثابت يسار الشاشة:** يظهر بسلاسة عند التمرير لأسفل ويصعد للأعلى بنعومة.
5. **نظام تتبع Google Ads مركزي موحد:** يرصد تلقائياً نقرات الاتصال والواتساب، ولا يسجل تحويل النموذج إلا بعد التأكيد الفعلي من الخادم بنجاح المعالجة دون تكرار.
6. **معالجة حقيقية للنماذج:** دعم وظائف الحافة `Cloudflare Pages Functions` عبر المسار `/api/contact`.
